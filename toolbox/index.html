공개 저장소의 코드를 복사하지 않고, 취재 흐름에 맞는 기능 원칙을 새로 구현했습니다.

원자료와 가공 기준을 함께 남기기

읽음 대신 ‘취재중·기사화·보류’ 상태 저장
검색·중복 제거·기간 비교를 기본값으로

현재 화면에서 쓰는 기능

발제 검색, 정책·기관/담당 기업 분류, 요약 보기, 발제 복사, 취재 상태 저장, DART·KIND·중기연구원 원문 바로가기를 넣었습니다. 상태는 사용 중인 브라우저에만 저장됩니다.

‘기자·언론사’는 저장소 설명이나 공개 이력으로 언론 프로젝트임을 확인한 경우입니다. ‘실무 도구’는 기자가 만들었다고 단정할 근거는 부족하지만 국내 뉴스 수집·분석·검증에 직접 활용할 수 있어 별도로 분류했습니다.

언론 프로젝트

1. 산업재해 사망 기록

2018~2019년 산업재해 사망 기록을 D3 그래프와 Leaflet 지도에 결합한 기사 프로젝트입니다.

가져올 점 숫자만 요약하지 않고 개별 사건 원자료와 시각화를 연결합니다.

언론 프로젝트

2. 반지하 가구 지도

경향신문 산업부와 진행한 반지하 가구 보도로, 행정구역별 검색과 인구 데이터 지도를 구현했습니다.

가져올 점 정책 수치를 지역·기업 단위로 내려가 검색할 수 있게 만듭니다.

언론 프로젝트

3. 코로나 세계 확산 지도

국제부와 확진·사망 데이터를 세계 지도와 서사형 기사에 결합한 프로젝트입니다.

가져올 점 시계열 자료는 발표 당일 수치보다 변화 경로를 먼저 보여줍니다.

언론 프로젝트

4. 밀레니얼 투자 리포트

설문 결과를 이용자 반응형 막대그래프로 보여준 투자 기사 페이지입니다.

가져올 점 설문·통계는 표본과 질문을 함께 남겨 수치의 한계를 드러냅니다.

언론 프로젝트

5. N번방 사건 타임라인

경향신문 사회부와 사건 전개를 시간순으로 탐색할 수 있게 만든 타임라인형 기사입니다.

가져올 점 인사·정책·분쟁처럼 이어지는 사안은 최신 기사와 앞선 변곡점을 연결합니다.

언론 프로젝트

6. 플라스틱과 탄소발자국

한국의 플라스틱 폐기물 문제와 탄소발자국을 다룬 디지털 기사 페이지입니다.

가져올 점 기업 발표를 규제·환경 통계와 교차해 광고성 재작성 위험을 줄입니다.

언론 프로젝트

7. 선거 인터랙티브

선거 결과와 지역 정보를 웹에서 탐색하도록 만든 대규모 시각화 프로젝트입니다.

가져올 점 국회·단체 선거는 인물보다 일정·선출 구조·표 단위를 먼저 구조화합니다.

언론 프로젝트

인물과 조직의 연결 관계를 네트워크 그래프로 표현하는 기반 코드입니다.

가져올 점 지분·계열·협회 인맥은 문장보다 관계 데이터로 먼저 저장합니다.

가져올 점 원자료, 기자가 붙인 분류, 주의사항을 분리해 재검증 가능성을 남깁니다.

가져올 점 거래 상대·지역·계열사를 붙여 단일 공시에서 보이지 않는 패턴을 찾습니다.

취재 데이터

가져올 점 하나의 결과 수치에 원인을 단정하지 않고 설명 변수 여러 개를 나란히 둡니다.

취재 데이터

가져올 점 경기지표·매출·고용처럼 성격이 다른 수치의 비교 단위와 시점을 맞춥니다.

가져올 점 전국 단위 발표를 담당 지역·산단·선거구 단위로 좁혀 후속 발제를 찾습니다.

가져올 점 검색이 막힌 PDF도 구조화해 인물·법인·금액별로 다시 찾을 수 있게 합니다.
