# Filing research node

Read `.codex/graph-common.md` first and follow it.

Inspect recent material disclosures for the assigned listed companies, prioritizing DART/KIND originals. Focus on contracts, investments, capex, securities issuance, M&A, governance, shareholder changes, litigation, auditor opinions, earnings surprises, major corrections and other developments that can support a fresh article.

Exclude routine periodic reports, immaterial corrections, trivial ownership changes and repetitive disclosures unless they become newsworthy through comparison or accumulation.

Write valid JSON to `graph_runs/filing.json` using the common contract. Use `agent` = `filing`. Do not edit any other file.
